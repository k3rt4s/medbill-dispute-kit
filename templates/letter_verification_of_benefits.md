# Template, Verification of benefits request

Use when an insured patient has planned or scheduled care and needs a written coverage record before service. Common triggers:

- A provider has quoted a procedure or supplied expected CPT or HCPCS codes.
- The patient needs confirmation of the deductible and out-of-pocket position before deciding whether to proceed.
- The facility may use separately billing professionals whose network status is unknown.
- The insurer has indicated that prior authorization may be needed.

This letter asks the insurer to give a written verification of benefits before service. It creates a record for planning and later comparison with the claim decision; it does not treat a phone call as sufficient confirmation.

---

```letter
[PATIENT FULL NAME]
[STREET ADDRESS]
[CITY, STATE ZIP]
Phone: [PATIENT PHONE]
Email: [PATIENT EMAIL]

[DATE]

[PLAN NAME]
[PLAN MAILING ADDRESS]

VIA CERTIFIED MAIL, RETURN RECEIPT REQUESTED
USPS Tracking: [CERTIFIED MAIL TRACKING NUMBER]

RE: Written verification of benefits request
    Member: [PATIENT FULL NAME]
    Member ID: [MEMBER ID]
    Group number: [GROUP NUMBER]
    Account #[ACCOUNT NUMBER]
    Date(s) of service: [DATE OF SERVICE]
    Balance asserted: $[CURRENT BALANCE]
    Planned service: [SERVICE / PROCEDURE], scheduled [SCHEDULED DATE]
    Quoted CPT/HCPCS code(s): [CPT/HCPCS CODE(S)]
    Facility: [PROVIDER OR FACILITY NAME]
    Separately billing professional(s): [PROVIDER NAME]

To Member Services / Utilization Management:

I request a written verification of benefits for the planned service above. Please provide a written response addressing each item below. A phone answer is not accepted because I need a record I can retain with the service and claim documents.

1. For each quoted CPT or HCPCS code, whether the service is covered under [PLAN NAME] and any material coverage limitation that applies.
2. My remaining deductible and remaining out-of-pocket maximum as of [DATE].
3. Whether [PROVIDER OR FACILITY NAME] is in network for the planned service and, for each professional identified above, whether that professional is in network or will bill separately.
4. Whether prior authorization is required for each quoted service, and, if so, the current authorization status and any authorization reference number.
5. A written reference number for this verification request and the name or department responsible for the response.

If the insurer needs additional information to answer, please identify the specific information needed in writing. Please send the written response to the address above.

Sincerely,



[PATIENT FULL NAME]

Member ID: [MEMBER ID]
Account number: [ACCOUNT NUMBER]
Scheduled date: [SCHEDULED DATE]
```

---

## Placeholders and rendering notes

- Use `[PATIENT FULL NAME]`, `[STREET ADDRESS]`, `[CITY, STATE ZIP]`, `[PATIENT PHONE]`, `[PATIENT EMAIL]`, `[DATE]`, `[PLAN NAME]`, `[PLAN MAILING ADDRESS]`, `[CERTIFIED MAIL TRACKING NUMBER]`, `[MEMBER ID]`, and `[GROUP NUMBER]` only from the member's insurance card, plan materials, or insurer correspondence.
- Use `[ACCOUNT NUMBER]`, `[DATE OF SERVICE]`, and `[CURRENT BALANCE]` only if already assigned. For an entirely pre-service request, omit the corresponding `RE:` line rather than inventing a value.
- Use `[SERVICE / PROCEDURE]`, `[SCHEDULED DATE]`, `[CPT/HCPCS CODE(S)]`, `[PROVIDER OR FACILITY NAME]`, and `[PROVIDER NAME]` from the provider's written quote or scheduling confirmation. If a separately billing professional is not known, state that fact in the letter rather than supplying a name.
- `[DATE]` is both the letter date and the requested as-of date for benefit accumulators. `[CERTIFIED MAIL TRACKING NUMBER]` remains unresolved until mailing.
- This is a request for a written coverage record, not a legal citation or promise of payment. Do not add plan-specific coverage, network, authorization, or deadline claims that have not been supplied in writing by the insurer.

## Before sending

1. Confirm the member ID, group number, plan mailing address, and the correct insurer department.
2. Obtain a written provider quote or scheduling confirmation identifying the planned service and any known CPT or HCPCS codes.
3. List each known separately billing professional. If one is unknown, ask the facility in writing to identify the expected biller.
4. Keep a copy of this request and its certified-mail receipt with the scheduling records.

## Parallel actions (same day as mailing)

- Send the same request through the insurer member portal if it supports secure written messages.
- Send the provider a written request to identify each expected separately billing professional and the associated CPT or HCPCS codes.
- Retain the provider quote, scheduling confirmation, plan card, and any written insurer response together.
- If uninsured or self-pay instead, use `templates/letter_good_faith_estimate_request.md`, which already covers the pre-service GFE request.

## Follow-up

- If the insurer responds in writing, retain the response and its reference number with the scheduling record.
- If the response identifies prior authorization as required, submit or coordinate that request before service and retain the resulting authorization record.
- If the insurer will not provide a written response, document that fact and avoid treating a phone answer as a coverage guarantee.
